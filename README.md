# HTML & CSS Fundamentals

## Overview

This repository is a collection of small HTML and CSS exercises and practice pages. It includes examples covering text and semantic elements, buttons, layouts with Flexbox and CSS Grid, positioning, and homework exercises. The `YT_Project` folder contains a larger YouTube homepage recreation, with its styles, icons, thumbnails, and other image assets.

## Purpose

I created this project to learn and practice the fundamentals of HTML and CSS by building pages and trying out layout and styling techniques. The exercises helped me put the concepts into practice, and I have now almost completed my study of these fundamentals.

## Getting Started

No setup or build tools are required. Open any `.html` file in a web browser to view it. To start with the larger example, open `YT_Project/youtube.html`.
